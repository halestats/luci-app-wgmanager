# 0.3.0-1 发布说明

发布日期：2026-10-20。面向已符合 README 适用条件的 iStoreOS / OpenWrt 24.10 既有 WireGuard 部署。

## 本版内容

- 增加 root 命令 `wgmanager manage-existing`：私有备份后接管原有 UCI Peer。
- 原有客户端可编辑名称/IPv4、禁用、启用、删除，持久化所选 Peer 配置。
- 保留原公钥、PSK、保活与端点，不重新生成旧客户端身份。
- 增加 UCI/运行状态双层校验、失败回滚、显式恢复与外部配置漂移检测。
- 包含 0.2.5 的 keepalive `off` 解析和主题标题修复，以及 0.2.6 的 LuCI 按钮属性修复。
- 保留所选布局、深浅主题、版本号、手机布局与新客户端配置/二维码导出。

## 安装与升级

按 [README](../README.md) 核对固定接口/端口/网段及至少 3 个既有客户端的首次保护基线，然后安装并运行 `wgmanager doctor`。旧版已经启用管理的设备不需要重复开启；需要管理原有客户端时显式执行 `wgmanager manage-existing`。安装或升级不会自动接管。

接管备份含密钥，只能在路由器私有保存。0.2.x 不识别接管后的记录，不要直接降级覆盖现有状态。旧客户端缺失私钥时不能导出二维码/完整配置。当前 IPv4 限制与部署约束见 README。

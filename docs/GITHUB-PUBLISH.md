# 仓库与发布清单

本仓库保存当前 0.3.1 的可阅读源码、构建脚本、文档、历史检查记录和可直接下载的发布文件。

| 路径 | 内容 |
| --- | --- |
| `root/` | IPK 安装到路由器的运行文件、LuCI 页面、rpcd 与采样器 |
| `scripts/` | 可复现 IPK 构建、演示生成、只读预检和卸载处理 |
| `tests/` | 策略、平台、浏览器、包结构与隔离内核检查源码 |
| `docs/` | FAQ、版本说明、安全设计、历史测试方法与结果 |
| `docs/images/` | 离线测试数据生成的界面图 |
| `docs/preview.html` | 下载后可在浏览器打开的离线演示 |
| `downloads/v0.3.1/` | IPK、源码分享 ZIP 与 SHA256SUMS |
| `reference/v0.1.0/` | 历史原型参考，不是当前安装载荷 |
| `SOURCE-SHA256SUMS` | 当前源码包内文件校验，排除下载目录及其自身 |

当前 0.3.1-1 安装包取消客户端数量下限，SHA-256 为 `e24736c38474c450182fac4ecb47325b7ab40d6b557e27db6b3efe991d807eb3`。源码分享包、文档和离线演示同步更新，校验值见下载目录。

历史交付包留在原开发工作目录，仓库保留 0.3.0 Release 和下载目录，不将其当成当前推荐下载。源码内的历史文档/日志保留版本标题，其网络写入边界以当前 README 的说明为准。

不得上传实际 `/etc/wgmanager/`、接管备份、路由器原 network 配置、真实私钥、PSK、客户端配置或二维码。测试夹具内的固定假密钥只用于测试，不可用于真实部署。


主页链接和地址配置说明在 0.3.1 发布后补充修正；已发布 IPK 和源码 ZIP 保持原发布快照。离线预览作为 Release 的独立 HTML 附件新增提供。最新说明以 main 分支 README 为准。

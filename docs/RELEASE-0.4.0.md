# 0.4.0-1 预发布说明

发布日期：2026-10-20。实现 wg IPv4/前缀驱动的地址池，保留 0.3.1 发布基线。

- 默认示例 192.168.66.1/24 不再是固定管理条件；按实际 wg 主 IPv4/前缀推导 /8–/30 池。
- 后端分配、地址验证、概览、新增/编辑提示读取同一份 network 数据。
- 核对配置地址与运行地址、直连路由；预览绑定网络配置，变化后要求重新预览。
- 新安装默认自动导出 wg/LAN 子网，可切换为自定义；旧版保存路由按自定义保留。
- 旧网段已管理记录显示地址需调整；不自动改号，恢复时跳过旧地址，可明确编辑迁移。
- 缺失旧网段 Peer 的迁移记录操作前是否存在，失败时恢复原本缺失状态。
- 保留原有客户端显式接管、单 Peer UCI 持久化、原服务端身份及不重启网络边界。

## 安装

```sh
opkg install /tmp/luci-app-wgmanager_0.4.0-1_all.ipk
wgmanager doctor
```

已经 manage 的设备无需重复启用或接管。新安装确认 wg 接口运行、doctor health 正常后执行 wgmanager enable-management，再新增第一个客户端。

doctor 新增 network 及 out_of_pool_count。接口改成 192.168.77.1/24 后，预期新分配及弹窗提示使用 192.168.77.2–254；这是实现目标，尚无本版功能测试/设备验收结果。

旧设备导出路由升级后保持原自定义值；需要自动跟随时在导出设置选择自动模式。已导入手机的配置需同步修改或重新导入。旧版本不支持新自动路由字段及新网段，不要直接降级沿用新状态。

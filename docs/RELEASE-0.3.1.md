# 0.3.1-1 发布说明

发布日期：2026-10-20。

## 修正首次安装的客户端数量限制

0.3.0 保留了最初目标部署“首次启用管理至少识别到 3 个既有客户端”的定制限制。它不是 WireGuard 协议要求，会阻止新系统从第一个客户端开始使用。

0.3.1 移除启用管理和持久状态读取中的数量下限，支持 0 个、1 个、2 个及更多客户端。服务端身份依然记录并核对，实际发现的既有客户端依然保护，需要显式接管后才能修改。零客户端的新部署无需执行 `manage-existing`。

## 新系统安装

必须先配置并运行符合 README 的 WireGuard 服务端：接口 `wg`、UDP `51820`、地址 `192.168.66.1/24` 与对应直连路由。插件不创建接口、不自动配置转发/NAT/防火墙。

```sh
opkg install /tmp/luci-app-wgmanager_0.3.1-1_all.ipk
wgmanager doctor
wgmanager enable-management
```

`doctor` 健康检查正常后再启用管理，然后在界面填写导出设置并新增第一个客户端。已经处于 manage 的旧设备升级后无需再次启用或接管。

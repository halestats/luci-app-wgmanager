# 0.5.0-1 预发布说明

发布日期：2026-10-21。本版合并多 IPv4 地址池和 WireGuard 接口选择。

- 同一接口的全部 IPv4 子网进入地址池；新增、编辑、地址校验、旧网段标记和恢复使用一致规则。
- 手填地址可选任一当前池，留空按接口配置顺序找空闲地址；跳过全部服务端地址、网络/广播地址、现有和禁用客户端及 AllowedIPs。
- 自动 AllowedIPs 包含所选接口的全部 IPv4 子网及 LAN 子网；原有自定义路由保留。每接口最多 16 个 IPv4 网段，路由最多 64 条。
- 发现原生 UCI/运行 WireGuard 接口；一个时自动识别，多个时选择。浏览器标签页各自记住目标，不改变其他页面的选择。
- 页面名称、状态、地址池、操作目标、管理模式、流量、导出设置及文件名按接口隔离。导出使用所选接口实际监听端口。
- RPC 显式传接口名，预览显示目标并绑定接口/端口/网络配置；弹窗及操作期间锁住选择，旧轮询响应不能覆盖新目标。
- 原 wg 沿用原目录，其他接口分目录保存；共用写锁避免 UCI 提交相互覆盖。ifup 恢复只操作对应接口，采样覆盖全部接口。
- 调整检查顺序，先明确指出未应用地址，再报告缺失直连路由。

## 升级

```sh
opkg install /tmp/luci-app-wgmanager_0.5.0-1_all.ipk
/etc/init.d/rpcd restart
wgmanager --interface wg doctor
```

RPC 参数变化，需要重启 rpcd 并强制刷新 LuCI，可能需要重新登录。该步骤没有重启网络或 WireGuard。单接口可省略 --interface，多接口的命令必须指定目标。

原 wg 已开启的管理模式、接管及状态保留。新接口先只读，使用 `wgmanager --interface vpn0 enable-management` 明确开启；需要管理其原有客户端时再执行对应的 manage-existing。

示例 wg 配置 192.168.77.1/24 和 192.168.66.1/24 时，两段范围均展示并可手动选择；留空优先从 .77 找空闲。LAN 为 192.168.95.1/24 时，自动路由为 .77.0/24、.66.0/24、.95.0/24。全部配置地址必须已应用到运行接口。已有客户端不自动改号。

重命名接口不会自动搬迁原名称的记录，旧私有目录保留。原有客户端私钥无法从服务端还原。IPv6、创建服务器、防火墙/NAT配置和公网映射端口独立设置不在本版范围。

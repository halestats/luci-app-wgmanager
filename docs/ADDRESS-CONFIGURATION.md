# 地址配置与界面提示

## 当前 0.3.1 的实际行为

服务端接口由 iStoreOS / OpenWrt 原生网络配置管理，插件不创建、修改或重启接口。插件读取 `wg` 的配置地址，但目前只接受固定条件 `192.168.66.1/24`、UDP `51820` 与对应直连路由。

客户端池和新增弹窗的说明仍固定在代码中，不能在插件界面改成其他网段。手填客户端 IPv4 仅允许池内地址。将 iStoreOS 的接口 IP 改为其他网段不会自动迁移客户端，管理检查会拒绝不匹配的环境。

“客户端 AllowedIPs”是导出配置中的目标路由，可自定义 IPv4 网段；默认的 `192.168.95.0/24` 只是最初目标部署的 LAN，不是从每台设备自动发现的结果。

## 合理的后续适配方式（尚未实现）

- 服务端 IPv4/前缀从实际配置的 `wg` 接口读取。
- 地址池按所选 IPv4 子网推导，排除网络地址、广播地址、服务端地址、其他已占用地址与禁用客户端保留地址。
- 新增/编辑弹窗的提示从同一后端分配规则返回，避免提示和校验不一致。
- 接口地址改变时重新显示实际范围，并明确处理旧客户端仍在旧网段的情况；不能悄悄改写现有客户端。
- 导出 AllowedIPs 继续允许用户选择实际家庭 LAN 或全 IPv4 路由；已保存的手动设置不应静默覆盖。

例如服务端配置为 `192.168.77.1/24` 时，适配后的默认池可为 `192.168.77.2–254`，弹窗也应显示该范围。但这只是后续设计示例，不代表 0.3.1 已支持该网段。

本次只修正下载入口并明确现有行为，没有实现自动适配或修改设备配置。

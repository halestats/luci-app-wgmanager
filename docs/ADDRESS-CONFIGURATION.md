# 0.4.0 地址自动适配

## 数据来源

接口仍为 `wg`。从已提交的 UCI `network.wg.addresses` 读取地址，首个 IPv4/前缀为主网段，其他本地 IPv4 也排除于客户端分配。主 IPv4 支持 /8–/30 的有效主机地址；没有可用配置时只显示默认示例 192.168.66.1/24，不能以此进行管理写入。

同时只读核对 `ip -4 address show dev wg` 的实际地址和相应直连路由。UCI 改了但尚未应用时返回 NETWORK_NOT_APPLIED，不按未生效的新网段写 Peer。

## 地址池与界面

池由主前缀内的可用主机范围推导，排除网络、广播及所有本地接口地址；自动分配跳过已有 UCI/运行 Peer 的 AllowedIPs 和插件记录（含禁用地址）。采用跳过区间的方式处理宽网段，不逐个扫描整个 /8。

后端 status/doctor 返回 network.server_address、subnet、prefix、pool_start、pool_end、excluded_addresses 和 hint。概览、新增及编辑弹窗均读取这些字段，弹窗打开期间也随页面轮询更新提示。

示例：192.168.77.1/24 → 192.168.77.2–254；10.8.0.10/24 → 10.8.0.1–254，排除 .10。

## 默认导出路由

新安装 routes_mode 为 auto，按当前 wg 子网与可解析的 network.lan 地址/掩码生成（最多 16 项）。LAN 地址若已带前缀可直接解析，否则读取 netmask；缺少有效掩码时不猜测 LAN。

升级的旧设置没有 routes_mode 标记时按 custom 保留，包含 0.0.0.0/0 等用户选择；用户可在导出设置切到自动。自动模式的后续状态和导出配置会使用最新网段，自定义模式不会被接口变化覆盖。

导出的配置不会远程改掉已经导入手机的配置，仍需同步修改/重新导入。

## 旧网段记录与迁移

状态校验允许保留旧 IPv4 记录，不因接口换网段而把整个状态判为损坏。超出当前池的已管理客户端标记 out_of_pool、显示“地址需调整”，不提供旧地址配置导出，也不能直接启用旧地址。

用户可明确编辑到新池，或者禁用/删除；不自动改号。接口重建时 restore 跳过旧池记录。对原本缺失的旧网段 Peer，迁移使用完整密钥参数重新添加，并记录 absent_before；回滚恢复操作前的缺失状态。UCI 归属、公钥和正常漂移检查继续有效。

主网段或 LAN 配置在预览后改变会使令牌失效，要求重新预览；接口配置在 Peer 写入过程中改变会使运行验证失败并进入原有回滚流程。

## 范围

本次不更改服务端接口，不启停网络服务，不改路由/NAT/防火墙。端口仍要求 UDP 51820；IPv6 地址池、IPv6 DNS/AllowedIPs、接口名称选择及任意独立手动地址池不在本版范围。

本版未运行功能测试，具体静态检查和历史结果见 TEST-RESULTS.md。
